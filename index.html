给 Vibe Coding 准备的 AI 协作任务看板。

一键导入已有 Markdown 任务清单，变成可拖拽、可检索、可审计的本地任务池；人类用桌面客户端规划进度，AI Agent 通过 MCP、HTTP、CLI 以受控权限读写同一份数据。

下载 v0.7.0去 GitHub 点亮 Star

支持 macOS Apple Silicon 与 Windows x64 安装包。

Why

Markdown 清单很好上手，但不适合长期交给 Agent 协作。

01

Markdown 清单越写越长，Agent 每次都要读大量无关文本。

02

任务状态藏在文字里，人很难一眼看清项目整体进度。

03

Agent 修改状态缺少统一入口，权限、审计、同步都容易散掉。

Import

从 Markdown 到任务池，不必推倒重来。

TangoForge 会解析你已有的任务 Markdown，先生成可审阅草稿，确认后再入库。既保留原来的工作习惯，又让任务变成结构化数据。

Features

人看得清楚，Agent 操作得准。

任务状态、项目资料、权限和审计被放进同一个本地协作层，AI 不再只是在一坨文本里猜上下文。

Markdown 一键导入

把现有任务清单解析成可审阅草稿，再确认入库。

可视化任务看板

看板、导航、全景图三种视角掌握任务状态与依赖。

Agent 三通道

MCP、HTTP、CLI 访问同一业务层，界面即时同步。

受控权限

Agent 默认只读，写操作按项目、按 action 显式授权。

本地离线存储

数据落在项目目录 `.taskboard/`，可随 Git 与团队同步。

审计日志

谁在什么时候改了什么，全部追加记录，可回看可导出。

可视化看板

规划任务、拖动流转、查看层级状态。

知识库检索

把任务关联资料变成可被 Agent 检索的项目记忆。

权限控制

按项目授权 Agent action，默认只读更安心。

审计日志

所有写操作记录 actor、action、target、result。

本地守护进程是人类与 Agent 之间的桥梁。

App 不需要一直前台运行。AI 需要操作任务时，后台服务可以被唤起；元数据保存在当前项目目录，团队可以通过 Git 同步，每个项目天然隔离。

Desktop Client

看板 / 导航 / 全景图 / 设置 / 权限

Local Daemon

识别 → 项目校验 → 权限 → 审计 → WebSocket 同步

AI Agent

Claude Code / Cursor / Copilot / CLI，经 MCP、HTTP、CLI 接入

Project Data
