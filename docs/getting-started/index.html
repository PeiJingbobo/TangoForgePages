快速开始

下载 TangoForge，导入项目工作目录，并把 Markdown 任务清单转成可视化任务池。

TangoForge 做什么

TangoForge 在人类和 AI Agent 之间放置一个本地任务协作层。桌面客户端负责看板、导航、全景图、权限配置；本地守护进程负责项目状态、任务流转、权限校验和审计日志。

安装

从 GitHub Releases 下载最新安装包：

下载 v0.7.0

首次使用

  1. 选择项目工作目录。
  2. 导入已有 Markdown 任务文件，或从空项目开始。
  3. 审阅导入草稿，确认后写入本地任务库。
  4. 给 Agent 配置项目级权限，默认保持只读。
  5. 通过 MCP、HTTP 或 CLI 让 Agent 读取任务并推进状态。
