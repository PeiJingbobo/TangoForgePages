下载 TangoForge

从 GitHub Releases 获取 TangoForge v0.7.0 安装包，支持 macOS Apple Silicon 与 Windows x64。

最新版本：v0.7.0

安装包由 GitHub Actions 自动构建并发布。macOS 未签名阶段首次打开需要手动允许，Windows 可能出现 SmartScreen 未知发布者提示。

打开 Release

macOS Apple Silicon

下载 dmg，双击后将 TangoForge 拖入 Applications。首次运行如提示无法验证开发者，可在终端移除隔离标记。

Windows x64

下载 setup.exe 安装包，或使用便携版 exe。若出现未知发布者提示，选择更多信息后继续运行。
